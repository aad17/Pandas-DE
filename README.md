# Pandas for Data Engineering: 15-Day Roadmap

A 15-day project-based roadmap focused on practical Pandas skills for Data Engineering and DE interview preparation.

## Roadmap

### Day 1 — E-commerce Order Explorer

**Topics:** Series, DataFrame, `read_csv()`, `head()`, `info()`, `shape`, `columns`, `dtypes`, column selection, basic filtering

### Day 2 — Dirty Banking Transactions

**Topics:** `isna()`, `fillna()`, `dropna()`, `duplicated()`, `drop_duplicates()`, `astype()`, `rename()`, basic string cleaning

### Day 3 — Hospital Claims Filter

**Topics:** Boolean filtering, multiple conditions, `isin()`, `between()`, `loc[]`, `iloc[]`, `sort_values()`, `nlargest()`

### Day 4 — Logistics KPI Pipeline

**Topics:** `groupby()`, `agg()`, named aggregation, `count()`, `sum()`, `mean()`, `min()`, `max()`, `nunique()`

### Day 5 — Payment Reconciliation

**Topics:** `merge()`, inner join, left join, right join, outer join, join keys, suffixes, `indicator`, merge validation

### Day 6 — IoT Event Processing

**Topics:** `to_datetime()`, `.dt`, date filtering, date arithmetic, `Timedelta`, date/time components

### Day 7 — Fraud Rule Engine

**Topics:** `apply()`, `map()`, vectorized operations, `assign()`, `np.where()`, conditional derived columns

### Day 8 — Regional Sales Reporting

**Topics:** `pivot_table()`, `melt()`, `stack()`, `unstack()`, wide vs long data

### Day 9 — SaaS Subscription Analytics

**Topics:** `shift()`, `diff()`, `pct_change()`, `cumsum()`, `cumcount()`

### Day 10 — Ranking Engine

**Topics:** `rank()`, `groupby().transform()`, per-group calculations

### Day 11 — CDC Deduplication

**Topics:** Latest-record patterns, multi-column sorting, `drop_duplicates()`, `groupby().idxmax()`, deterministic deduplication

### Day 12 — Incremental ETL

**Topics:** `concat()`, schema alignment, incremental processing, anti-join using `merge()`, append + deduplicate patterns, idempotency

### Day 13 — SCD Type 2

**Topics:** SCD Type 2, change detection, new/changed/unchanged records, effective dates, current flags, historical tracking

### Day 14 — Nested JSON Pipeline

**Topics:** `read_json()`, `json_normalize()`, nested JSON flattening, `explode()`

### Day 15 — Production Pipeline / Boss Fight

**Topics:** `chunksize`, `memory_usage()`, categorical dtype, vectorization, performance optimization, reusable functions, pipeline organization
